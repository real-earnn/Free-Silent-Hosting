# Free Silent Hosting — Public Releases

Public release repository for **Silent Hosting Free** — the free tier of Silent Hosting.

- Windows installer: tag `Silent-Host-Free-Windows`
- Android APK: tag `Silent-Host-Free-Android`

The apps themselves live in the private repos `Silent-Hosting-Free-Exe` and `Silent-Hosting-Free-Apk`; their workflows publish releases here.
